## State closure and restore contract

`RuntimeAdapter` reflects concrete owners for the selected official task:
outer/inner wrappers, robot, OSC, enabled linear interpolators, Panda gripper,
fixtures, objects, task state, observables, MuJoCo data, RNG owners, and
callbacks. Every concrete path must be one of `SERIALIZED`,
`DERIVED_RECONSTRUCTED`, `IMMUTABLE`, or `PROVEN_UNUSED`; unknown paths abort
construction or restore.

Important closed state includes:

- complete `mjSTATE_INTEGRATION`, with exact `mj_setState`/`mj_getState`
  readback before `mj_forward`;
- OSC `initial_joint`, goals, `new_update`, `relative_ori`, `ori_ref`, and all
  enabled linear-interpolator state;
- Panda gripper persistent action and physical state;
- wrapper counters, observable timers/cursors/caches, task state, object joint
  state, global Python/NumPy RNG, environment generators, and loaded Torch CPU
  RNG;
- explicit `nplugin` and `npluginstate` checks, plus explicit sleeping markers;
- every LIBERO goal predicate as exact discrete state.

The object `joints` property is accepted only through its registered property
descriptor, a `sequence[str]` shape/type proof, and pinned robosuite source
evidence. Unsupported nonempty interpolators, plugin state, sleeping state, or
opaque mutable values block M1.

Authoritative restore always sets `authoritative=true` and
`strict_provenance=true`. A fresh environment is created and reset once for
construction. After restore begins there is no reset, `set_init_state`, settle,
dummy action, autoreset, retry, policy import/inference, or tape generation.
Compiled physics-relevant `mjModel` arrays are never patched. Fixture/model
pose mismatch blocks before the integration-state write.

The h=0 observation is read with
`inner._get_observations(force_update=False)` after restoring the observable
cursor/cache. It is not generated by a dummy action or forced refresh.

## Static identity

Identity is split into two exact interfaces:

- `physics_model_fingerprint()` covers dynamics options; dimensions and names;
  body, joint, geom, actuator, equality, tendon, plugin, collision/BVH, mesh
  geometry, site attachment, and other execution arrays.
- `observation_model_fingerprint()` covers cameras, lights, visual materials,
  colors, textures/resources, and renderer configuration.

Every exposed compiled NumPy array must be classified into one interface;
unknown C-extension properties fail closed. Clean M1 requires both hashes to
match. The split allows a later camera/light intervention to change only the
observation identity while retaining the physics identity, but M1 performs no
such intervention.

## Null and dynamic acceptance

Null evidence is a prerequisite, not a fallback tolerance:

- at least 20 distinct complete duplicate-control run pairs;
- every selected trace has at least five pairs;
- every regime has at least five pairs;
- contact, grasp, and carried regimes contain independent positive contact-rich
  evidence;
- physical envelopes are keyed by `regime × quantity × horizon`; no global
  maximum or post-hoc multiplier exists;
- renderer envelopes are keyed by
  `camera × observation-key × regime × horizon`.

Exact/discrete values always require exact equality: action bytes, contact
identity, goal predicates, success/done/termination semantics, counters, and
gripper discrete state. Floating physical differences must be no larger than
the matching null group. Missing groups fail closed.

Duplicate controls must be bitwise identical. If their RGB outputs are all
bitwise identical, replay RGB must be exact. Otherwise the report publishes
the differing-pixel count, maximum absolute pixel error, and mean error for
each group; replay may not exceed any measured group maximum. Renderer
variability never widens a physics envelope.

Each frozen window requires three same-process restores and three distinct
fresh Python process restores. Fresh workers load persisted capture, tape,
source suffix references, null envelopes, and frozen registry; construct one
environment; report PID/environment/restore trace/output SHA; and perform no
retry.

the M1 judgment and never starts CC/CS/SC/SS or M2.
