# G1-E2.4 — Role-bound structural metadata decoding

## Verdict and scope

E2.4 is **ACCEPT** for the fixed asset. The generic symbolic VM remains
value-opaque; this separate layer reads only literals whose symbolic paths are
proved by the machine-generated E2.3 authority graph. No NumPy import,
deserialization, reducer execution, BUILD execution, or physical-buffer read
is performed.

The E2-local semantic predicates are **COVERED** by the evidence below. The
validation/use consistency predicate remains explicitly
`CROSS_PACKAGE_DEPENDENCY_ON_FUTURE_ADMISSION` and is not silently counted as
an E2-local failure.

## Fixed authority and fail-closed rules

The authority source is
`G1-E2.3-authority-graph.json`, generated by
`scripts/m1_e2_authority_graph.py`; this report does not introduce a second
hand-maintained graph. The extractor requires the fixed outer asset SHA-256

`cbbc73792ce546c9bec181fd328a411d3183074840b282671dee481511381d0a`

and validates the exact operation/node topology:

| offset | authority / object | graph binding |
|---:|---|---|
| 104 | `_codecs.encode` | `REDUCE_RESULT#5` |
| 110 | `numpy.core.multiarray._reconstruct` | `REDUCE_RESULT#11` |
| 152 | `numpy.dtype` | `REDUCE_RESULT#17` |
| 184 | dtype `BUILD` | target `REDUCE_RESULT#17`, state `TUPLE#21` |
| 43851 | `_codecs.encode` | `REDUCE_RESULT#20` |
| 43857 | ndarray `BUILD` | target `REDUCE_RESULT#11`, state `TUPLE#30` |

Any mismatch in the caller-provided asset-hash binding, operation offset/opcode
set, authority string, node kind/path, literal opcode, or approved path returns
`UNRESOLVED` (hash mismatch raises `ValueError`). The extractor does not
independently authenticate outer bytes; that binding remains a validation/use
dependency. The allowlist is symbolic-path based; printable content and length
are never used as heuristics.

## Decoded fields

Every field is classified as `STRUCTURAL_METADATA`, `PHYSICAL_OPAQUE`, or
`AUTHORITY_REFERENCE` in the extractor output.

### dtype REDUCE at 152

`REDUCE@152.args.TUPLE#13` has exactly three leaves:

| path | opcode | value | classification | role |
|---|---|---|---|---|
| `...BINUNICODE#14` | `BINUNICODE` at 138 | `f8` | `STRUCTURAL_METADATA` | NumPy legacy scalar/type descriptor (`float64`) |
| `...NEWFALSE#15` | `NEWFALSE` at 147 | `False` | `STRUCTURAL_METADATA` | alignment flag |
| `...NEWTRUE#16` | `NEWTRUE` at 148 | `True` | `STRUCTURAL_METADATA` | copy flag |

The fixed `f8` descriptor is an exact built-in scalar/simple floating dtype,
not a structured dtype. Its descriptor contains no field dictionary or nested
dtype descriptor, and the dtype BUILD flags are zero; therefore
`hasobject = false` and nested object fields are absent. This is a source-level
semantic conclusion, not an inference from the absence of `GLOBAL` opcodes.

### dtype BUILD at 184

`BUILD@184.state.TUPLE#21` has arity 8. The role map is:

| index | offset/opcode | value | classification | role |
|---:|---|---|---|---|
| 0 | 156 `BININT1` | 3 | `STRUCTURAL_METADATA` | dtype pickle/state version |
| 1 | 158 `BINUNICODE` | `<` | `STRUCTURAL_METADATA` | byte order |
| 2 | 166 `NONE` | `None` | `STRUCTURAL_METADATA` | subarray descriptor absent |
| 3 | 167 `NONE` | `None` | `STRUCTURAL_METADATA` | fields mapping absent |
| 4 | 168 `NONE` | `None` | `STRUCTURAL_METADATA` | names tuple absent |

### ndarray BUILD at 43857

`BUILD@43857.state.TUPLE#30` has arity 5, matching the pinned NumPy
`__setstate__` schema:

| index | path | value | classification |
|---:|---|---|---|
| 0 | `.version` | `1` | `STRUCTURAL_METADATA` |
| 1 | `.shape` | tuple arity 2, dimensions `50, 92` | `STRUCTURAL_METADATA` |
| 2 | `.dtype` | `BUILD@184 -> REDUCE_RESULT#17` | `AUTHORITY_REFERENCE` |
| 3 | `.order` | `False` (`isFortran`) | `STRUCTURAL_METADATA` |
| 4 | `.data` | not read | `PHYSICAL_OPAQUE` |

The raw `BINUNICODE` at offset 188 and its `_codecs.encode` result at offset
43851 are both physical opaque. The latter is the ndarray `rawdata` field;
neither bytes nor decoded numerical state are present in the report, graph, or
serialized metadata output.

## Regression checks

`tests/test_m1_e2_metadata.py` covers:

1. exact `f8` extraction at the canonical dtype path, dtype/ndarray arities,
   `hasobject = false`, and physical payload opacity;
2. no raw descriptor/physical marker in generic `inspect()`, authority graph,
   or serialized metadata;
3. fixed asset hash drift failing closed;
4. canonical symbolic-path/offset drift failing closed; and
5. an empty/unapproved allowlist leaving the same opcode opaque.

The focused suite runs as **3 passed** in the pinned runtime. The broader M1
suite is environment-blocked in this shell by the pinned PyTorch/NumPy ABI
(`RuntimeError: Numpy is not available`) in unrelated runtime replay tests;
that failure does not alter the focused E2.4 result.
