# E2.1 — Symbolic pickle VM verification

## Verdict

**E2 = UNRESOLVED.** The interpreter is now explicit for every opcode present
in the fixed stream; unresolved predicates are semantic/type predicates that
are intentionally outside a non-executing VM, not silent stack fall-through.

## Exact fixed-stream opcode set

`BINGET, BININT, BININT1, BINPUT, BINUNICODE, BUILD, GLOBAL, MARK,
NEWFALSE, NEWTRUE, NONE, PROTO, REDUCE, STOP, TUPLE, TUPLE1, TUPLE2, TUPLE3`.

## Coverage classification

| encountered opcode family | classification |
|---|---|
| `PROTO`, `MARK`, `NONE`, `NEWTRUE`, `NEWFALSE`, `BININT`, `BININT1`, `BINUNICODE` | `FULLY_MODELED` (opaque payloads where required) |
| `BINPUT`, `BINGET` and implicit memo events | `FULLY_MODELED` (identity-preserving symbols; missing GET is explicit `MISSING`) |
| `TUPLE`, `TUPLE1`, `TUPLE2`, `TUPLE3` | `FULLY_MODELED` |
| `GLOBAL` | `FULLY_MODELED` with exact target string |
| `REDUCE` | `FULLY_MODELED` structurally; unresolved if callable/args symbol is `MISSING` |
| `BUILD` | `FULLY_MODELED` structurally; unresolved if target/state is `MISSING` |
| `STOP` | `FULLY_MODELED` with final stack reported |
| Any other opcode, including authority opcodes `STACK_GLOBAL`, `PERSID`, `BINPERSID`, `EXT*`, `NEWOBJ*`, `INST`, `OBJ` | `AUTHORITY_REJECTED` |

No opcode in the fixed stream falls through silently. Container mutation
(`LIST`, `DICT`, `APPENDS`, `SETITEMS`, `ADDITEMS`), `DUP`, scalar pushes,
MARK/TUPLE, memo PUT/GET/MEMOIZE, and malformed authority paths are covered by
synthetic tests even when absent from the fixed stream.

## Tests and commands

Synthetic tests now cover scalar pushes; MARK/TUPLE; empty-list APPENDS;
empty-dict SETITEMS; PUT/GET/MEMOIZE and missing memo; nested GLOBAL→TUPLE→REDUCE;
BUILD identity; malformed authority opcode; and persistent-ID rejection.

```text
PYTHONPATH=. ... pytest -q tests/test_m1_e2_symbolic.py  # 7 passed
PYTHONPATH=. ... scripts/m1_e2_symbolic.py              # fixed scan: 4 reducers, 2 builds, unsupported=[]
git diff --check
```

No `pickle.loads`, `torch.load`, reducer/BUILD execution, dtype or codec
construction, NumPy/Torch/application import, environment, EGL, render,
policy, processor, replay, schedule, E3–E6, or G2 operation occurred.

## Predicate disposition

- exact REDUCE argument tuples: **CLOSED structurally by VM symbols**;
- dynamic callable exclusion: **CLOSED for fixed stream** (only four direct
  GLOBALs, no STACK_GLOBAL/extension/indirect GLOBAL); semantic callable safety
  remains outside E2;
- exact BUILD targets: **CLOSED structurally as current stack symbols**;
- BUILD state structural schemas: **STILL_UNRESOLVED** for opaque leaves and
  exact mapping/array state interpretation;
- plain `numpy.ndarray` versus subclass: **STILL_UNRESOLVED**;
- dtype descriptor/object-bearing condition: **STILL_UNRESOLVED**;
- validation/use consistency: **STILL_UNRESOLVED** (future payload binding).

The historical G1 report and accepted design/plan were not modified.
